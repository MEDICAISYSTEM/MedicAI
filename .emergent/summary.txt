<analysis>**original_problem_statement:**
The user wants to build a full-stack application called MedicAI, an intelligent medical management system for a clinic.

**PRODUCT REQUIREMENTS:**
-   **Communication Module:** Integrate with WhatsApp Business API via Make.com webhooks to receive real-time patient messages.
-   **AI Brain:** Use Google Gemini (specifically Gemini 1.5 Pro/Flash) to analyze natural language and determine patient intent (Appointment, Urgency, Price inquiry).
-   **Data Layer:** Use Supabase as a relational database to store chat history, patient data, and clinic availability.
-   **Admin Panel:** A web application for medical staff to view appointments confirmed by the AI.
-   **Workflow:**
    1.  A patient sends a WhatsApp message, captured by a Make.com webhook.
    2.  The system checks if the patient's phone number exists in Supabase.
    3.  The Gemini AI processes the message. If it's a new patient, it asks for their name. If it's an emergency, it alerts the staff.
    4.  The AI suggests available appointment times. Upon confirmation, it creates an entry in Supabase and sends a confirmation message to the patient.
-   **Technical Specifications:**
    -   Backend: Python (FastAPI).
    -   Authentication: JWT-based authentication for the admin panel.
    -   AI Prompting: The AI must be restricted from giving medical diagnoses and focus only on administrative tasks.
-   **Multi-tenancy SaaS Model:**
    - The application should support multiple doctors/clinics.
    - A Super Admin panel is required to manage clinics, create doctor accounts, and view global statistics.
    - Each doctor should have their own isolated view of their patients, appointments, and data.
    - A system of personalized WhatsApp links should be used to identify which clinic a patient is contacting.
